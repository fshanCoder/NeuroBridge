# Flutter 客户端

Android 优先，iOS 共享业务状态和组件。手机使用底部导航，平板使用侧栏；患者各页固定保留求助入口。首页布局自上而下为连接与相机状态、预览、可放大的字幕、常用需求、求助。横屏优先保证字幕和需求按钮可达。

| 角色 / 页面 | 主要操作 | 反馈与恢复 |
|---|---|---|
| 登记向导 | 手机验证、患者资料、病史、联系人、关联医生、分项同意、校准、基线 | 可中断续填；拒绝相机后进入短语板；未成年人记录监护授权 |
| 患者 / 沟通 | 选择唇读或手势、点选饮水等短语、切换语言、接收文字回复 | 待确认候选支持重选或跳过；已确认文本进入字幕，离线优先使用短语缓存和系统 TTS |
| 患者 / 情绪与手势 | 手动报告感受、查看近期记录、录制自定义动作、设置停留时长 | 明示识别建议与本人报告；校准失败可重试或换输入 |
| 患者 / 进展与设置 | 查看日周月记录、调整字体、声音、阈值、隐私及联系人 | 无基线提示先建档；撤回某项授权后关闭对应处理 |
| 照护者 / 患者状态 | 查看最近消息、活动、设备电量、位置、提醒与求助 | 展示更新时间；可确认接手、联系患者、记录处理结果或误报 |
| 医生 / 患者详情 | 从授权患者列表进入，查看情绪时间线、治疗前后对照、写随访记录、导出报告 | 比较区展示日期、有效次数及缺测；导出中可离页，完成后重新鉴权下载 |

## 沟通与告警交互

摄像头 → 本地 MediaPipe 特征 → TFLite 分类 → 候选确认 → 字幕、翻译与朗读 → SQLite 事件队列。相机开启时持续显示标识。无可用目标语言语音时保留字幕，并显示当前朗读可用语言。联系人键入回复后，患者端直接展示大字幕。

疑似跌倒或静默先弹出“你还好吗？”，提供大按钮、个性化眨眼或开关输入。确认时长可根据反应能力延长。主动求助直接进入本机声光振动反馈；界面独立显示远端发送状态和接手人。网络中断时明确提示“仅本机报警，等待联网”。患者取消后保留取消事件并同步到照护端。

## 无障碍验收

按钮至少 56 dp，文字与图标并列；读屏顺序跟随视觉顺序。扫描导航可暂停，停留选择可调整时长。用单开关完成选短语、确认和取消；用大字体横屏完成求助；禁用相机和网络后验证短语板、字幕、本机求助仍可用。
